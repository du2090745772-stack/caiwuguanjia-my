# 每日记账本 · 可跳转原型

本目录把 Stitch 导出的独立页面整理成一个可浏览的静态原型。页面内容和视觉以原始设计为基础，入口及页面关系参照 [PRD V1.0.1](../001产品PRD（产品经理）/每日记账本-产品需求文档PRD-V1.0.1.md) 第五章。注册与登录已对接 [`框架开发/`](../../框架开发) 的账号服务（`/api/v1/auth/*`，用户名与密码摘要存 MySQL）；账单、预算与个人资料仍保存在当前浏览器的 localStorage 中，账单备份上云的接口尚未接入。

## 运行

在 `框架开发/` 执行 `npm start`（需要 `.env` 与 MySQL 实例，见该目录 `.env.example`），再访问 `http://127.0.0.1:3000/`。后端会把本目录当静态站点一起托管，页面与账号服务同源，不涉及跨域，本机只需要起这一个进程。

想用独立端口看页面，也可以在本目录执行 `python3 -m http.server 8080` 后访问 `http://localhost:8080/`；这属于跨域来源，后端 CORS 白名单默认放行 `localhost:8080` 与 `127.0.0.1:8080`，其他来源（例如 Cursor Live Server 的 `:5500`）要先加进 `.env` 的 `CORS_ORIGINS` 再重启后端。双击 HTML 以 `file://` 打开则一律连不上账号服务，浏览器不允许。

## 页面关系

- 着陆页可进入免登录流水，也可进入登录页。
- 主导航连接流水、统计、预算、我的；“记一笔”进入记账原型。
- 每页右下角的“页面导航”可访问全部 15 张页面，包括空态和弹窗态。移动端应用页另有底部主导航。
- 登录页的“立即注册”跳转至独立注册页，注册页可返回登录页。注册与登录都走账号服务；清除站点数据会清掉本机 Token 与账单，但用户名仍在服务端，用同一凭据可重新登录。
- 账单、预算、自定义分类、支付账户和个人资料保存在当前浏览器。头像上传会裁切压缩到 160×160 像素后保存。登录页可导出本机账单 CSV。
- 统计图和每日金额清单可横向滚动；统计、预算页右上角的年月控件可前后切换月份，点击中间可选择年、月、日。记账日期仍使用浏览器原生日期选择器。

## 后续开发边界

PRD 中的 PG-05 账单详情与 PG-08 搜索页尚无 Stitch 设计稿；PG-07 暂以记账页的“管理分类”弹窗承载。部分示例金额和图表仍是静态样例。账号认证已接服务端（argon2id 哈希、用户名／IP 限流与递增锁定、Access 2 小时 + Refresh 30 天），本机只留 Token；跨设备备份与账单上传接口仍待接入，账号注销与冷静期清理也还没做。正式上线前需抽离重复的页面壳和设计 Token。
