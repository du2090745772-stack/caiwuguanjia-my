# 每日记账本 · 可跳转原型

本目录把 Stitch 导出的独立页面整理成一个可浏览的原型。注册、登录及已登录用户的账单、分类、预算、统计和个人资料已接入 [`框架开发`](../框架开发) 的 MySQL 服务。未登录时原型仍可展示本机数据；登录后旧的 `localStorage` 账单保留在浏览器，页面会提示用户核对并手动确认合并，合并前不会自动上传或删除。

## 运行

最省事的方式是双击 `../框架开发/双击启动.command`：它等价于在该目录执行 `npm start`，并自动打开 `http://127.0.0.1:3000/pages/auth.html`。手动起就是在 `004前端开发/框架开发` 执行 `npm start`（需要 `.env` 与 MySQL 实例，见该目录 `.env.example`）。后端会把本目录当静态站点一起托管，页面与账号服务同源，不涉及跨域，本机只需要起这一个进程。

**不要双击本目录里的 HTML 打开**：`file://` 页面被浏览器当作独立来源，不允许访问 `127.0.0.1:3000`，注册会直接报连不上账号服务，这是浏览器限制，前端改不掉。

想用独立端口看页面，也可以在本目录执行 `python3 -m http.server 8080` 后访问 `http://localhost:8080/`；这属于跨域来源，后端 CORS 白名单默认放行 `localhost:8080` 与 `127.0.0.1:8080`，其他来源（例如 Cursor Live Server 的 `:5500`）要先加进 `.env` 的 `CORS_ORIGINS` 再重启后端。直接双击 HTML 时，页面会尝试跳转到 `127.0.0.1:3000`；请先启动后端，否则浏览器会显示连接失败。

## 页面关系

- 着陆页可进入免登录流水，也可进入登录页。
- 主导航连接流水、统计、预算、我的；“记一笔”进入记账原型。
- 每页右下角的“页面导航”可访问全部 15 张页面，包括空态和弹窗态。移动端应用页另有底部主导航。
- 登录页的“立即注册”跳转至独立注册页，注册页可返回登录页。注册与登录都走账号服务；清除站点数据会清掉本机 Token 与尚未合并的旧账单，云端数据仍可用同一账号登录查看。
- 登录后，账单、预算、自定义分类、个人资料和头像保存在 MySQL。头像上传前会裁切压缩到 160×160 像素。旧浏览器账单保持原样，用户确认后才逐笔合并。
- 统计图和每日金额清单可横向滚动；流水、统计、预算页可切换年月。记账日期使用浏览器原生日期选择器。统计页面可导出 Excel 可打开的 `.xls` 文件。

## 后续开发边界

PRD 中的 PG-05 账单详情与 PG-08 搜索页尚无 Stitch 设计稿；PG-07 由记账页的分类管理承载。已登录页面从数据库读取数据，未登录原型仍展示本机示例状态。账号认证使用 argon2id、登录限流、Access 与 Refresh Token；账号注销有 7 天冷静期，期间重新登录可撤销。正式上线前仍需统一页面壳、设计 Token，并补完整的搜索页。
