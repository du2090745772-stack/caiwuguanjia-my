# 每日记账本 · 可跳转原型

本目录把 Stitch 导出的独立页面整理成一个可浏览的静态原型。页面内容和视觉以原始设计为基础，入口及页面关系参照 [PRD V1.0.1](../001产品PRD（产品经理）/每日记账本-产品需求文档PRD-V1.0.1.md) 第五章。当前仍是前端演示：账号、账单、预算和个人资料保存在当前浏览器的 localStorage 中，不含后端账号服务或真实云备份。

## 运行

用 Cursor 的 Live Server 打开 `index.html`；或在本目录执行 `python3 -m http.server 8080`，然后访问 `http://localhost:8080/`。本地账号需要 `localhost` 环境，请通过本地服务器预览。

## 页面关系

- 着陆页可进入免登录流水，也可进入登录页。
- 主导航连接流水、统计、预算、我的；“记一笔”进入记账原型。
- 每页右下角的“页面导航”可访问全部 15 张页面，包括空态和弹窗态。移动端应用页另有底部主导航。
- 登录页的“立即注册”跳转至独立注册页，注册页可返回登录页。注册和登录可使用当前浏览器的本地账号；清除站点数据会删除本地内容。
- 账单、预算、自定义分类、支付账户和个人资料保存在当前浏览器。头像上传会裁切压缩到 160×160 像素后保存。登录页可导出本机账单 CSV。
- 统计图和每日金额清单可横向滚动；统计、预算页右上角的年月控件可前后切换月份，点击中间可选择年、月、日。记账日期仍使用浏览器原生日期选择器。

## 后续开发边界

PRD 中的 PG-05 账单详情与 PG-08 搜索页尚无 Stitch 设计稿；PG-07 暂以记账页的“管理分类”弹窗承载。部分示例金额和图表仍是静态样例。账号密码摘要保存在浏览器，仅供前端演示，不具备真实服务端认证和跨设备备份能力。正式上线前需接入后端账号 API 与安全存储，并抽离重复的页面壳和设计 Token。
