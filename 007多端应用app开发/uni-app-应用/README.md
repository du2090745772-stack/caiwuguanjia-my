# 翔翔记账 uni-app 多端应用

基于现有 uni-app Vue 3 初始化项目开发，可编译到 iOS、Android 和微信小程序。页面沿用 `004前端开发/画面设计` 的粉色视觉体系，包含着陆、登录注册、流水、统计、预算、个人主页、账号安全等入口；记账和预算调整使用弹窗。Excel 导出按要求未加入。

## 目录

- `pages/index/index.vue`：页面与交互
- `pages/index/page.css`：跨端样式
- `services/ledger.js`：本地数据模式与现有后端 API 适配
- `config/api.js`：多端共用的接口配置；登录页不要求用户输入地址
- `manifest.json`：App / 微信小程序配置
- `pages.json`：页面入口

## 使用

1. 用 HBuilderX 打开此目录，运行到微信开发者工具、iOS 或 Android 设备。默认账号服务地址为 `http://121.4.120.161:88/api/v1`；设备需能访问这一地址，并先启动 `004前端开发/框架开发` 中的账号服务。
2. 登录与注册页面一直可打开。开发运行且账号服务可访问时可以登录和注册；服务暂时未启动时仍可选“本地体验”，其数据只保存在当前设备。
3. 正式构建默认沿用上述服务器地址；也可设置 `VITE_API_BASE_URL=https://你的域名/api/v1` 覆盖。修改地址后必须重新打包并安装新版 App。微信小程序还需配置服务器合法域名和 HTTPS 地址。
4. 旧的本地账单不会自动覆盖云端，可在“账号与安全”手动合并；重复合并使用本地账单 ID 避免重复写入。
