# 翔翔记账 · 产品说明书

**适用对象：** 最终用户、客户运营负责人及授权管理员  
**文档版本：** 1.0  
**编制日期：** 2026 年 11 月 22 日  
**覆盖范围：** 网页用户端、后台管理系统、iOS／Android／微信小程序共用的 uni-app 应用

## 1. 产品介绍

翔翔记账是一款面向个人日常收支管理的轻量记账产品。用户可以随手记录收入和支出，按月份查看流水、分类统计和预算使用情况，也可以先免登录体验，再决定是否注册账号。产品采用温和的手账风格，常用操作集中在“流水、记一笔、统计、预算、我的”几个入口。

产品由三个部分组成：

| 产品部分 | 面向谁 | 主要用途 |
| --- | --- | --- |
| 网页用户端 | 个人用户 | 在浏览器中记账、查看统计、管理预算及账号 |
| 多端应用 | 手机用户、微信小程序用户 | 在 iOS、Android 和微信小程序中使用主要记账功能 |
| 后台管理系统 | 获授权的管理员 | 查看云端用户、账单汇总、预算分析和服务状态 |

三个部分共享同一套账号与云端账本服务。**免登录体验的数据只保存在当前浏览器或设备中**；只有登录后保存到云端的数据，才能由同一账号在不同设备间读取，也才能进入后台统计。

## 2. 用户角色与数据范围

| 角色 | 可以做什么 | 数据范围 |
| --- | --- | --- |
| 免登录体验者 | 记账、管理本地分类与预算、查看统计和个人资料 | 当前浏览器或当前设备的本地数据 |
| 注册用户 | 使用完整账本功能，管理账号资料，并在支持的设备上登录 | 自己账号的云端数据；本地旧账单可按提示手动合并 |
| 后台管理员 | 查看全站概览、用户及账单、分析与导出 | 已注册且已保存到云端的业务数据，后台不代用户修改账单 |

后台管理员使用独立账号，不通过普通用户注册页创建。当前版本未开放“运营查看者”等其他后台角色。

## 3. 主要使用流程

### 3.1 首次使用

1. 打开网页着陆页或移动端应用。
2. 选择“免登录体验”，直接开始本地记账；或选择注册，设置用户名和密码并同意隐私条款。
3. 注册成功后进入个人账本。以后可使用同一账号登录。

### 3.2 记录一笔收支

1. 点击“记一笔”。
2. 选择支出或收入，填写金额、分类、日期和可选备注。
3. 保存后在流水中查看；如需纠正，可进入该笔账单编辑或删除。
4. 支出会同步计入所选月份的统计与预算使用额。

### 3.3 查看月度账本

1. 在“流水”切换月份，查看该月收入、支出、结余和账单明细。
2. 在“统计”查看收支汇总、支出分类占比及趋势；选择分类可查看相应数据。
3. 在“预算”设置月度总预算或分类预算，查看已用、剩余及超支提示。

### 3.4 从本地体验转为账号使用

本地账单不会因登录而自动覆盖云端账本。登录后，如页面提示存在未合并的本地账单，请先核对，再由用户主动执行合并。换浏览器、卸载应用或清理设备数据前，应先确认需要保留的本地账单已经合并。

### 3.5 管理员查看业务情况

管理员在独立后台登录，选择日期范围和筛选条件，依次查看概览、用户、账单、分析、预算与系统状态。需要留存结果时，可导出当前筛选范围的数据。

## 4. 功能说明

### 4.1 网页用户端

| 功能 | 说明 |
| --- | --- |
| 着陆与账号 | 提供产品介绍、免登录入口、注册、登录和退出登录 |
| 流水账本 | 按月查看收支、结余及账单；新增、修改、删除自己的账单 |
| 分类管理 | 使用预置分类，也可维护自定义分类；历史账单保留原有记录 |
| 搜索 | 从页面顶部搜索手账内容，可查找页面或账单相关内容 |
| 统计报表 | 查看月度收支、分类占比和趋势；部分统计页提供表格导出 |
| 预算管理 | 设置总预算与分类预算，查看已用金额、剩余金额和超支状态 |
| 个人主页 | 查看记账概况，维护昵称、简介和头像，进入账号安全设置 |
| 账号安全 | 修改密码、退出登录、申请注销账号；注销设有 7 天冷静期 |

网页端页面包含空账本、空预算和超支等状态。界面中的“页面导航”主要用于浏览原型的全部页面，正式交付时应以正常业务导航为准。

### 4.2 iOS、Android 与微信小程序

多端应用使用同一套主要页面和业务逻辑，包括着陆页、登录注册、流水、记一笔、分类、搜索、统计、预算、个人主页、存钱小金库与账号安全。存钱小金库按已记录的月度收入减支出展示结余。头像可从设备选择图片并处理后保存。

移动端**不提供 Excel 导出**。当账号服务地址尚未部署或设备无法连接服务时，可继续使用本地体验；此时注册登录及跨设备同步不可用。本地体验的账单不会自动成为账号云端账单。

“支持构建”与“已完成真机验收”是两回事：当前代码可构建微信小程序、App 和 H5，但正式发布前仍须在实际 iPhone、Android 手机及微信环境中完成界面、键盘、头像和网络测试。

### 4.3 后台管理系统

| 模块 | 管理员可查看的内容 |
| --- | --- |
| 数据概览 | 注册用户、记账用户、账单笔数、收入、支出、结余及每日趋势 |
| 用户管理 | 按用户名、状态、时间搜索和翻页；查看用户资料、近期账单及预算 |
| 账单查询 | 跨用户按日期、收支类型、分类、备注、金额和删除状态筛选，查看详情 |
| 收支分析 | 按日／月趋势、分类占比与排行、用户记账频次分布 |
| 预算与分类 | 月度预算覆盖率、使用率、超支人数、分类统计 |
| 账号与系统 | 注销申请、登录异常、数据迁移及数据库连接状态 |
| 数据导出 | 导出当前筛选范围的用户、账单或每日收支汇总为 `.xlsx` |

后台业务查看为**只读**：管理员不能从后台替用户新增、编辑或删除账单。后台不展示免登录本地数据，不导出密码、头像、完整备注、IP 或设备标识。单次导出上限为 10,000 行，超出时应缩小筛选范围。

## 5. 用户操作说明

### 5.1 注册与登录

在网页或已连接账号服务的移动端打开登录页。新用户选择“立即注册”，输入符合页面提示的用户名和至少 6 位密码，确认隐私条款后提交。已有账号输入用户名和密码登录。如连续输错密码，系统可能暂时限制登录，请稍后再试；不要反复提交。

### 5.2 记账、修改与删除

进入“记一笔”，先确认收支类型，再填写金额、分类和日期。保存后返回流水核对金额和备注。需要调整时打开该账单的编辑入口；删除前确认目标账单。删除后，该账单不再计入常规收支与预算统计。

### 5.3 使用预算与统计

预算按自然月管理。先选择月份，再设置月度总预算；如希望单独控制餐饮、交通等支出，可为分类设置预算。统计页的月份和分类选择会改变展示范围。金额与账单不一致时，优先检查当前月份、收支类型及分类筛选条件。

### 5.4 修改资料与退出

进入“我的”或“个人主页”，选择“编辑资料”修改昵称、简介或头像。退出登录后回到未登录状态；已保存的云端账单仍保留在账号下，本地体验数据则留在当前设备。注销账号与普通退出不同，应仔细阅读页面提示，并在需要时先备份数据。

### 5.5 管理员使用后台

管理员使用单独分配的后台地址和账号登录。先在“数据概览”选时间范围，再到“用户管理”或“账单查询”进一步筛选。查看单个用户或账单时点击列表项目。下载前再次核对日期和筛选项，避免导出不需要的数据。完成工作后点击退出后台。

## 6. 技术架构与部署关系

客户只需理解为“**界面、账号服务、数据库**”三层：

```text
浏览器用户端 ──────┐
iOS / Android 应用 ─┼── 账号与账本服务 ── MySQL 数据库
微信小程序 ────────┘           │
                              └── 后台管理系统读取云端业务数据

免登录体验 ── 当前浏览器或当前设备的本地存储
```

- **网页用户端**位于 `004前端开发/画面设计`，由 HTML、CSS、JavaScript 构成；配套账号与账本服务位于 `004前端开发/框架开发`，使用 Node.js、Express 和 MySQL。同源部署时，一个服务即可提供网页与用户接口。
- **后台管理系统**位于 `006后台管理系统`，有独立页面和独立服务，默认本机运行端口为 `3100`。管理员会话与普通用户登录态分开。
- **多端应用**位于 `007多端应用app开发/uni-app-应用`，使用 uni-app、Vue 3 和同一套用户接口构建 iOS、Android、微信小程序及 H5。
- **本地数据**只在当前设备保存；**云端数据**保存在 MySQL，并通过账号鉴权限制为用户本人访问。后台仅面向已授权管理员。

正式上线需要准备可公开访问的 **HTTPS 账号服务地址**，并在移动端构建配置及微信小程序后台设置相应域名。局域网 IP `192.168.1.4:3000` 只用于当前开发调试，不能作为正式交付地址。后台也应使用受控访问地址、HTTPS 和独立管理员密钥。详细部署步骤应以最终上线环境和运维交接单为准。

## 7. 常见问题

**问：免登录体验的账单会同步到其他手机吗？**  
答：不会。它只保存在当前浏览器或设备。登录后可按提示主动合并本地账单；合并完成后再到其他设备登录核对。

**问：为什么 App 或小程序能打开，却不能注册和登录？**  
答：界面可以本地运行，但账号功能需要可访问的账号服务。正式包还需要 HTTPS 接口地址；微信小程序另需配置服务器合法域名。

**问：为什么后台看不到某位免登录用户的账单？**  
答：后台只统计已注册并保存到云端的数据，无法读取用户设备里的本地账单。

**问：退出登录会删除账单吗？**  
答：普通退出只结束当前登录状态，不会删除已保存到云端的账单。申请注销账号是另一项独立操作。

**问：统计金额和我看到的账单不一致怎么办？**  
答：先检查月份、收支类型、分类筛选及账单日期；已删除账单不计入常规统计。本地模式与账号模式的数据也可能不同。

**问：能否把账单导出为 Excel？**  
答：移动端没有 Excel 导出。后台管理员可按筛选范围导出 `.xlsx`；网页端的部分统计或账单页面保留相应导出入口，以页面实际提供的格式为准。

**问：后台能帮用户修改账单吗？**  
答：不能。后台业务页面用于查看和核对，账单修改应由用户本人在自己的账本中完成。

**问：换手机前需要做什么？**  
答：确认本地体验数据已按需合并到账号，记住登录账号，并在新设备登录后核对账单。仅保存在旧设备本地的数据不会自动出现。
